# עיתון המהפכה - The Revolution Times

A fully designed Hebrew news website set on January 21, 1793 - the historic day of King Louis XVI's execution.

## 🌟 Features

### Pages
- **Home (index.html)** - Breaking news about Louis XVI's execution
- **World (world.html)** - International reactions to the French Revolution
- **Travel (travel.html)** - Travel guides through revolutionary France
- **Gossip (gossip.html)** - Royal scandals and celebrity gossip

### Design
- **Hebrew RTL Layout** - Proper right-to-left text direction
- **1793 Newspaper Aesthetics** - Old paper texture, period fonts, decorative elements
- **Historical Accuracy** - Set on כ"ט בטבת תקנ"ג (29 Tevet 5553) / January 21, 1793
- **Responsive Design** - Works on desktop, tablet, and mobile devices

### Interactive Features
- **Comments System** - Post, like, reply, and report comments
- **Newsletter Signup** - Subscribe to daily revolutionary news
- **Poll Voting** - Interactive polls about revolutionary topics
- **Dynamic Counters** - Execution counter, view counts, engagement metrics
- **Popup Alerts** - Revolutionary notifications and urgent messages
- **Easter Eggs** - Hidden Konami code feature

### Content Highlights
- Clickbait/ragebait articles about historical events
- Marie Antoinette still ordering cakes in prison
- Robespierre's mysterious romantic partner
- International war declarations
- Travel warnings for dangerous regions
- Fashion and lifestyle in revolutionary times

## 🚀 Getting Started

### Viewing the Website

1. Clone the repository
2. Open `index.html` in a web browser
3. Or run a local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`

### Navigation
- **בית (Home)** - Main page with featured articles
- **עולם (World)** - International news
- **טיולים (Travel)** - Travel guides
- **רכילות (Gossip)** - Gossip and scandals

## 📰 Historical Context

**January 21, 1793** was a pivotal day in the French Revolution:
- King Louis XVI was executed by guillotine at 10:22 AM
- This marked the end of absolute monarchy in France
- It triggered international outrage and war declarations
- Marie Antoinette remained imprisoned in the Temple

The website captures this historic moment with:
- Period-accurate language and styling
- References to actual historical figures (Robespierre, Danton, Marat)
- Real events (Bastille storming, Vendée uprising, Coalition Wars)
- Authentic revolutionary slogans: "חירות • שוויון • אחווה" (Liberty, Equality, Fraternity)
